# 🖱️ Bl4ckTap

**Bl4ckTap est un autoclicker Windows** qui automatise les clics de souris pour les tâches répétitives. Il permet de choisir le clic gauche, droit ou les deux, la vitesse et un mode maintien ou continu.

## 📋 Prérequis

- **Windows** avec **.NET Framework 4.8**.
- Si tu télécharges les sources, **compile le projet** avec la commande ci-dessous pour obtenir l'exécutable. Visual Studio et Python ne sont pas nécessaires.

## 🚀 Lancement

**Tu as déjà l'exécutable ?** Double-clique sur **`Bl4ckTap.exe`**. Après compilation, il se trouve dans le dossier **`bin/`**.

**Tu as téléchargé les sources ?** Ouvre PowerShell dans le dossier contenant `build.ps1`, puis exécute :

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
.\bin\Bl4ckTap.exe
```
